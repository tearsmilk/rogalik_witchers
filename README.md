# Ведьма-ученица (rogalik_witchers)

Прототип рогалика с ордами врагов и видом сверху. Юная ведьма проспала экзамен, а бесы растащили
гримуар наставницы по Проклятому лесу. Нужно найти 3 страницы, выбрать школы магии и одолеть Короля бесов.

## Что есть в прототипе

- Бег (WASD), рывок (Пробел), пауза (Esc). Искра сама целится в ближайшего врага, зажатая ЛКМ — стрельба в курсор.
- Враги: бесы, летучие мыши, слизни; каждые ~45 с — бес-хранитель со страницей гримуара.
- Опыт → уровень → выбор 1 из 3 улучшений.
- Страница гримуара → выбор школы (Огонь, Лёд, Природа, Гроза): новое заклинание и смена образа
  (1-я страница — платье, 2-я — шляпа, 3-я — аура).
- Цветы в лесу собираются в букет и дают пассивные бонусы.
- После 3 страниц появляется Король бесов; победа — «экзамен сдан» (с отличием, если быстрее 8 минут).

## Запуск из исходников

```bash
npm install
npm start
```

Или просто открыть `src/index.html` в браузере.

## Сборка для macOS

DMG (универсальный: Intel + Apple Silicon, macOS 11+) собирает GitHub Actions на каждый push —
workflow `Build macOS DMG`, файл лежит в артефакте `Witch-Apprentice-macOS`. На Mac можно собрать и локально:

```bash
npm ci && npm run dist:mac
```

Приложение не подписано сертификатом Apple. После копирования в «Программы» один раз выполнить в Терминале:

```bash
xattr -cr "/Applications/Witch Apprentice.app"
```

```bash
codesign --force --deep --sign - "/Applications/Witch Apprentice.app"
```

Первая команда снимает карантин, вторая ставит локальную ad-hoc подпись (без неё на Mac с Apple Silicon
приложение считается «повреждённым»). Дальше — правый клик → «Открыть».

### Сборка DMG в Linux (без Mac)

```bash
npx electron-builder --mac dir --arm64 --x64 --publish never
```

Затем каждый `.app` упаковывается в DMG-образ (ISO 9660 + Rock Ridge, macOS его монтирует):
`xorriso -as mkisofs -V "Witch Apprentice" -R -o Witch-Apprentice-mac-arm64.dmg <папка с .app и ссылкой на /Applications>`.
Подписи такая сборка не получает — см. команды выше.
