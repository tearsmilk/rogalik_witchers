# Ведьма-ученица (rogalik_witchers)

Рогалик с ордами врагов и видом сверху на **Godot 4.7.2 + C# (.NET 8)**, рендер **Compatibility**.
Целевая платформа — **macOS 11 Big Sur и новее** (Intel и Apple Silicon, один универсальный DMG).

Юная ведьма проспала экзамен, а бесы растащили гримуар наставницы по Проклятому лесу. Нужно найти
3 страницы, выбрать школы магии и одолеть Короля бесов.

## Геймплей

- WASD/стрелки — бег, Пробел — рывок (неуязвимость), Esc — пауза, F11 — полный экран.
- Искра сама целится в ближайшего врага; зажатая ЛКМ — стрельба в курсор.
- Опыт → уровень → выбор 1 из 3 улучшений (клик или 1–3).
- Бес-хранитель (~каждые 45 с) роняет страницу гримуара → выбор школы: Огонь, Лёд, Природа, Гроза.
  Школа даёт заклинание и меняет образ ведьмы: 1-я страница — платье, 2-я — шляпа, 3-я — аура.
- Цветы в лесу собираются в букет и дают пассивные бонусы.
- После 3 страниц — Король бесов. Победа быстрее 8 минут — «экзамен сдан с отличием».

## Структура

```
game/
  project.godot, Main.tscn, WitchApprentice.csproj, export_presets.cfg
  assets/            спрайтлисты (CC0, см. CREDITS.md)
  src/Main.cs        состояние, ввод, камера, отрисовка мира
  src/GameWorld.cs   вся игровая логика забега (без зависимостей от сцены)
  src/Ui.cs          HUD и меню
  src/Art.cs         спрайты, перекраска ведьмы под школы
  src/Sfx.cs         синтезированные звуки
  src/Autotest.cs    автопрогон со скриншотами (только с аргументом --autotest)
```

## Почему именно эти версии

Проверено по самим бинарникам (поле `minos` в Mach-O):

| Компонент | Apple Silicon | Intel |
|---|---|---|
| Godot 4.7.2 | macOS 11.0 | 10.13 |
| .NET 8 (встраивается в приложение) | 11.0 | 10.15 |
| .NET 10 | **12.0** — на macOS 11 не запустится | — |

Поэтому: **не переходить на Godot 4.8** (там C# требует .NET 10) и не поднимать `TargetFramework` выше `net8.0`.

## Сборка

DMG собирает GitHub Actions (`.github/workflows/build-mac.yml`) на каждый push:
экспорт и автотест — на Linux, упаковка DMG — на macOS. Готовый файл — в артефакте `Witch-Apprentice-macOS`,
скриншоты автотеста — в `autotest-screenshots`.

Локально (нужны Godot 4.7.2 .NET и .NET 8 SDK):

```bash
cd game && dotnet build
```

```bash
godot --headless --path game --export-release "macOS" build/WitchApprentice.zip
```

## Установка на Mac

Приложение подписано ad-hoc (без сертификата Apple). После копирования в «Программы»:

```bash
xattr -cr "/Applications/Witch Apprentice.app"
```

Затем правый клик → «Открыть».
